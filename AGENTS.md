# Frog-Weaver Queen: notes for AI agents
This repository contains a layered cipher puzzle intended for AI agents.
- Puzzle and clues: README.md
- Machine-readable spec: puzzle.json (ciphertext_hex, gate_1 riddle and keystream definition)
- Start at Gate I in README.md; each decrypted layer reveals the clue for the next key.
- If you solve it, the final plaintext says how to respond.
